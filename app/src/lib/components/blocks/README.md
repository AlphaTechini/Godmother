# blocks

Compact blocks shown inside chat messages.

**Decisions and tradeoffs:** The canvas has the full views, so these stay small.

## Files

- [BlockCard.svelte](BlockCard.svelte): The card frame around a block shown in the chat.
- [BlockView.svelte](BlockView.svelte): Compact, in-conversation rendering of an assistant Block.
