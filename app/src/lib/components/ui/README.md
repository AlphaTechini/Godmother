# ui

Small shared UI pieces.

**Decisions and tradeoffs:** Kept free of session logic so they can be used anywhere.

## Files

- [ImageViewer.svelte](ImageViewer.svelte): Full-screen view of one image.
- [Plate.svelte](Plate.svelte): An image frame for try-on results and product shots.
- [Spinner.svelte](Spinner.svelte): The loading spinner.
- [StartDialog.svelte](StartDialog.svelte): Shown when someone not signed in presses Start.
- [Swatch.svelte](Swatch.svelte): A colour swatch.
- [ThemeToggle.svelte](ThemeToggle.svelte): The Evening and Daylight switch.
- [UnitsMeter.svelte](UnitsMeter.svelte): YouCam units spent against what this person may spend, with the ledger in a popover.
- [Wordmark.svelte](Wordmark.svelte): The logo: a glass slipper with two sparkles.
