# Godmother

> **Prepare for the gala.**

Godmother is an AI agent that gets you ready for an event. Tell it about the event (or upload the invitation) and it finds the dress code, colours and setting, then shows **you** wearing the outfit, shoes, accessories, makeup and hairstyle that fit, with a priced shopping list for anything you don't already own. Try-on and face analysis run on the [YouCam API](https://yce.perfectcorp.com/ai-api).

Built for the **YouCam API Skin AI & eCommerce VTO Hackathon** (eCommerce VTO track).

**Status: pre-build.** The YouCam capabilities the app depends on are being verified first.
